   ```bash

   ```

2. **Local Server** (optional):
   ```bash
   python3 -m http.server 8000
   # Then visit: http://localhost:8000
   ```

3. **Deploy**:
   - Upload all files to any web hosting
   - Files needed: `profile.html` and `profile.jpg`
   - Ensure both are in the same directory
